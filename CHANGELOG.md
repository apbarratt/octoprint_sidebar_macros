# Changelog

## 0.4.3

This patch release prepares Sidebar Macros for OctoPrint 2.0.0.

### Fixed

- Prevent an error when migrating macro settings that have no stored settings version.

### Changed

- Add automated compatibility testing against OctoPrint 2.0.0.
- Remove an unused frontend dependency.

No configuration changes are required. Existing macros continue to work as before.
